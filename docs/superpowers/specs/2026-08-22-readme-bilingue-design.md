# Design do README bilíngue do Olimpandas

## Objetivo

Criar um `README.md` informativo para apresentar o Olimpandas como um projeto acadêmico em desenvolvimento, voltado ao aprendizado prático de Unity, C#, desenvolvimento de jogos 2D e colaboração com Git/GitHub.

## Público e idiomas

O conteúdo principal será escrito em português brasileiro. Ao final, haverá um resumo em inglês com as informações essenciais, evitando duplicar integralmente o documento e mantendo a leitura objetiva.

## Estrutura do conteúdo

O README terá:

1. Título e descrição curta do projeto.
2. Aviso explícito de que se trata de um projeto acadêmico com foco em aprendizado.
3. Visão geral do party game 2D competitivo e de seu loop de partidas.
4. Estado atual do protótipo, sem apresentar funcionalidades planejadas como concluídas.
5. Lista das funcionalidades já implementadas.
6. Controles dos dois jogadores.
7. Tecnologias e versão do Unity utilizadas.
8. Instruções para clonar, abrir e executar o projeto no Unity Editor.
9. Organização resumida das principais pastas.
10. Roadmap compatível com o planejamento acadêmico.
11. Limitações atuais e aviso de que o projeto ainda não é uma versão final.
12. Resumo em inglês com propósito, recursos atuais, controles e instruções de execução.

## Fontes de verdade

As funcionalidades e os controles serão descritos a partir dos scripts, prefabs, cena e configurações existentes no repositório. O PDF de planejamento será usado apenas para contexto, objetivos e roadmap. Itens futuros serão identificados claramente como planejados.

## Decisões editoriais

- Não incluir badges de build, cobertura ou publicação que ainda não existam.
- Não declarar uma licença enquanto não houver um arquivo de licença no repositório.
- Não publicar nomes, e-mails ou dados pessoais da equipe no README.
- Não adicionar imagens externas ou capturas temporárias.
- Usar linguagem simples, acadêmica e acolhedora para pessoas que estejam aprendendo.

## Critérios de aceite

- O README deixa evidente, nos dois idiomas, que o Olimpandas é acadêmico e voltado ao aprendizado.
- O estado atual é distinguido do roadmap.
- Os comandos e controles correspondem aos arquivos do projeto.
- O Markdown renderiza com hierarquia clara e sem links quebrados.
- Nenhum segredo ou novo dado pessoal é introduzido.
